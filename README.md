# Автопилот «Сам решу»

Каждый день около 10:00 по Москве готовит пост по стратегии (Reels или карусель) про Сама и Надо,
присылает его в Telegram на проверку и после кнопки «Публиковать» выкладывает в Instagram.

- Контент-план — `plan.yaml` (дописывайте эпизоды в конец).
- Персонажи и правила тона — `autopilot/characters.py`.
- Эталоны персонажей — `refs/sam.png` и `refs/nado.png` (команда /refs в боте).

Команды боту: `/post` — сделать пост сейчас, `/review` — снова показать текущий черновик,
`/refs` — нарисовать эталоны заново.

Согласование обязательно. `AUTO_PUBLISH` больше не отключает проверку.
Бот показывает все медиа и полный текст. Кнопка «Публиковать в Instagram» разрешает выход
показанной версии сразу при обработке кнопки; автоматического выбора будущего времени нет.
После повторной отправки черновика используйте только последнюю кнопку: прежние кнопки
и согласование изменённого текста или файлов недействительны. «Переделать» ожидает комментарий,
а «Пропустить» отклоняет пост. Эта кнопка публикации больше не дублирует пост во ВКонтакте;
отдельные команды `/vk_all` и сторис сохраняются.

При ошибке после начала публикации повторная отправка заблокирована. Проверьте Instagram
и Actions, затем вручную разберите запись `publication_attempts` в `state.json`; не удаляйте её,
пока не исключён уже вышедший пост. Это предотвращает автоматические дубли при потерянном ответе API.

GitHub Actions запускается с возможными задержками. Бот слушает сообщения ограниченными
сеансами (см. `.github/workflows/poll.yml`), поэтому кнопки вне сеанса могут ждать следующего запуска.
Для немедленной обработки запустите workflow «Кнопки из Telegram» вручную. Существующий бот
публикует через Instagram API; подключение Metricool в Codex не передаёт ему доступ автоматически.

Проверки без токенов, генерации и публикации: `python -m unittest discover -s tests -v`.

Правила текстов — `strategy/rules.md` (выжимка из гида). Reels оживляются в SYNTX вручную (бот присылает кадры
и промпты, клипы отправляются ответом), через Veo (переменная `VIDEO_MODE` = `veo`) или собираются из кадров
без анимации (`still`). Голоса — Google Text-to-Speech, отключаются переменной `VOICES` = `off`.
